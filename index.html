Actualización de los niveles

Los datos del gráfico se obtienen del archivo niveles.csv de este repositorio.

Para agregar una nueva medición de 2026, editá el archivo en GitHub e incorporá una nueva fila con el número de día, la fecha y el nivel correspondiente.

Las series históricas y actuales se alinean por día de comparación, no por fecha calendario. Este gráfico no representa una comparación de mediciones tomadas el mismo día y año.
